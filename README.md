# ドライブ先提案アプリ 🚗

現在地・ドライブ圏内・目的を入力するだけで、今すぐ行ける最適なドライブスポット（営業中）を提案するWebアプリです。

## 🌟 主な特徴

- **AIによるキーワード自動拡張**: 「エモい夜カフェ」などの抽象的なワードを、Gemini APIが検索に最適な類似キーワードへ拡張します。
- **高精度なGoogleスポット検索**: Google Places API (Text Search) を利用し、関係のない駅やファストフードを排除した精度の高いスポット検索を行います。
- **移動時間と営業時間を考慮**: Google Distance Matrix API で車での正確な移動時間を計算し、到着時に営業しているか（閉店・ラストオーダー）を自動算出します。
- **メニューと魅力を自動抽出**: 評価と口コミ数による独自スコアで上位10件を選出。Gemini APIが口コミから代表メニュー3選と魅力を要約します。
- **インスタ連携**: 提案をきっかけに、ワンクリックでInstagramの投稿を検索・チェックできます。
